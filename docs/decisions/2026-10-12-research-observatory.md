# Research Observatory：工程决策

日期：2026-10-12；目标版本：0.2.4；基准 main：27780a0dd68a16ea6d16f6d369fea46bf48476b2。

- **背景与传播目标。** 已有一篇限定范围数学审查、历史 Skill 对照评估和实验性物理适配。看板将这些不同证据并列呈现，方便读者追溯来源，不以审查篇数或方法规范数量代表能力评分。
- **技术选择。** 使用 GitHub Pages 的 main 分支 /docs 部署，HTML5、CSS3 与空 .nojekyll 即可满足静态展示。无需框架、数据库、外部图表、CDN、追踪或密钥；不使用构建工具链或常驻服务器。
- **页面结构。** 双语品牌与四项锚点导航；Hero；四个概览卡片；桌面左侧研究审查、右侧证据状态双栏；科研目标说明与社区参与；证据优先页脚。采用白底、海军蓝、细边框和系统字体，移动端纵向排列。
- **证据来源与维护。** GitHub 已提交的 Skill、论文档案、评估档案及适配文件仍是依据。静态 HTML 只作摘要，手动随版本更新；所有科研入口使用绝对 GitHub 链接。check-observatory.py 核对版本、已登记论文／卡片、Core/OAC 数量、历史报告数量、状态限定、资源与锚点。不推断科研结论、不自动抓取数据。
- **验证。** 本地一致性检查通过：版本 0.2.4、1 篇审查、4 条 Core、6 项 OAC、3 份历史评估；所有页面链接及资源目标可在源仓库核对。现有 Edge 无窗口预览完成：1280px 桌面截图呈现四卡及双栏，375 CSS 像素手机布局纵向排列；DOM 宽度检查无横向溢出。Edge 命令行最小窗口大于 375px，手机检查使用仓库外临时 srcdoc iframe 的实际 375px 内容视口，不修改网页源码。焦点样式、原生链接和跳转正文入口均已设置。SKILL 仅两处版本字符串变化；历史 docs、审查证据与原打包脚本不改。
- **部署状态。** 提交前为 DEPLOYMENT PENDING / NOT VERIFIED。推送后执行一次真实 HTTP 检查，以执行回报为准。GitHub Pages 由用户在 Settings → Pages 选择 Deploy from a branch、main、/docs，并通过 Visit site 验证；本轮不调用 API 修改仓库设置。
- **已知限制。** 本地预览不证明公网部署已生效，也未做完整辅助技术审计；最终上线需核对首页版本及 CSS。看板是人工维护的有限摘要，不是独立事实源；未证明可靠的普适增量收益，也未产生新的科研验证。发行 ZIP 复用原白名单，网站 HTML/CSS 不进入 SkillHub 包。
- **下一逻辑节点。** 真实 Skill ON/OFF Regression，由科研负责人另行授权；本轮不执行。SkillHub ZIP 由用户手动上传。

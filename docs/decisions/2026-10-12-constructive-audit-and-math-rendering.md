# 精选研究、建设性审查与公式展示：工程决策

日期：2026-10-12；目标版本：0.2.3；基准 main：b1a5ecf518bb6e286d2e19e29c79abb9ba8b0bd9。

1. **背景。** 首篇 Jarzynski 1997 限定范围数学审查已正式归档。首页、协议与报告需要更清楚地说明选文意义；报告仍含 GitHub 不正确展示的旧数学定界符及与 Reviewed 状态冲突的摘要措辞。
2. **呈现方式。** 强调精选研究、原创贡献与建设性的物理—数学复现，针对具体命题记录成立条件与边界；不是对论文或作者评定通过／失败。开放问题和未审查部分不自动构成错误，真实反例与无依据外推也不能因友好措辞而被隐藏。
3. **目标与科学意义。** 说明为何所选案例有研究价值，区分原论文贡献、审查者复现与一般化候选。APS 将该论文收入 Letters from the Past 回顾系列，作为选文背景；声誉不替代数学证据。欢迎自愿反馈，不暗示作者认可或参与。
4. **实际文件。** 修改 SKILL.md、两份 README、CHANGELOG.md、literature-audits/README.md、docs/literature-audit-protocol.md 和 Jarzynski 正式报告；新增 scripts/build-skillhub-zip.py 及本记录。原始脚本、输出和执行记录不改；运行文件仅改两处版本字符串。
5. **数学展示修复。** 按 [GitHub 官方说明](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions)，将报告 50 个行内数学定界符对转换为 `$...$`，20 个显示数学定界符对转换为独立行的 `$$`。逐个比对表达式内容、配对及 aligned 环境，避开代码、URL 和普通转义。数学含义不变。
6. **发行包兼容。** 标准库脚本只选 SKILL、两份 README、references 内已发布 Markdown 及许可证；LICENSE 在包内改名 LICENSE.md，包内 README 的对应本地链接随之调整，源文件不变。排序、entry 时间戳与权限固定，验证路径、重复名、CRC、完整字节和版本。不包含论文档案、测试、docs、AGENTS、PDF 或私人记录，不覆盖已有 ZIP。必须核对干净工作树、HEAD、origin/main 与实际远端 main 一致。
7. **提交前验收。** 70 个公式定界符对全部完成静态检查，公式正文不变；十个内容单元和八项协议证据要求保留；三个原始证据 SHA-256 不变；计数仍为 1；中英介绍对应，相对链接可解析；YAML 解析、脚本语法、路径拒绝及包内许可证链接转换检查通过。原工作区 1,736 个既有文件和状态未变。最终 ZIP 按要求在普通推送并 fetch 核验后执行一次构建，实际结果记录在执行回报中；此提交前记录不声称 ZIP 已经生成。
8. **局限与失效条件。** 目前仅完成依据官方语法的静态兼容性检查，未做实际 GitHub 页面视觉验证。跨 Python/zlib 版本的压缩字节不保证相同。白名单包不是完整项目文档镜像，README 的论文、docs 等导航目标保留为源仓库导航；仅许可证链接在包内改写。脏工作树、未同步提交、危险路径、缺失必需文件、版本不一致或已有目标 ZIP 均应停止构建。历史执行记录中的旧草稿相对链接按前轮用户授权保留，索引已注明历史路径。
9. **下一逻辑节点。** Skill ON/OFF 回归实验，由科研负责人另行决定和授权；本轮不启动实验、不提出 Core/OAC 架构修改，也不新增能力增益结论。SkillHub 由用户手动上传。

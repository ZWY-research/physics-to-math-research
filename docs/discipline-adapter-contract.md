# Discipline Adapter Contract / 学科适配契约

Status: Experimental supporting guidance; not a Core rule or independent Skill.

状态：实验性支持指引；不是 Core 规则或独立 Skill。

1. Applicability: Use discipline guidance only when domain-specific information can materially alter the current formulation or inference.
   适用性：仅当领域信息能够实质改变当前数学表述或推理时使用。

2. Semantic grounding: Identify relevant observables, domain quantities, and admissible constraints before committing to a mathematical representation.
   语义基础：建立数学表述前，识别相关观测量、领域变量和可接受约束。

3. Conditional guidance: Treat domain conventions as candidates requiring applicable premises, not universal laws.
   条件性：学科惯例必须有适用前提，不得作为普遍定律直接采用。

4. Mathematical freedom: Do not prescribe mathematical structures solely from a discipline name.
   数学自由：不得仅凭学科名称规定数学结构。

5. Evidence boundary: Separate observations, established premises, provisional models, and conditional mathematical conclusions.
   证据边界：区分观察、已确立前提、暂定模型及条件性数学结论。

6. Non-interference: Do not replace, repeat, or override the canonical Core/OAC. Ignore irrelevant domain checks and avoid additional output templates.
   非干扰：不得取代、重复或覆盖 Core/OAC；忽略不相关检查，不新增固定输出模板。

7. Cross-disciplinary applicability: Adapters are not mutually exclusive. Resolve domain conflicts using task-specific evidence and assumptions.
   跨学科：适配层可以组合，冲突依据具体问题的证据和前提处理。

8. Regression accountability: Evaluate material benefit and negative transfer before promoting an experimental adapter.
   回归责任：实验性适配层正式推广前应检查实际收益及负迁移。

A discipline label is an index, not a mathematical model selector.

学科标签是检索索引，不是数学模型选择器。

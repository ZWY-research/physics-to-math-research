## What a mature case may record / 成熟案例可记录什么

1. Original scientific problem / 原始科学问题。
2. Observed facts and evidence / 观测事实与证据。
3. Initial formulation / 初始 formulation。
4. Skill/model response, with version and context where known / Skill 或模型回答，以及已知的版本和环境。
5. Community critique / 社区审查。
6. Competing formulation or counterexample / 竞争性 formulation 或反例。
7. Final claim status, including unresolved limits / 最终 claim 状态，包括尚未解决的限制。
8. Whether a Skill change was warranted, and why / 是否需要修改 Skill，以及理由。
9. Regression derived from the failure, if applicable / 如适用，由 failure 导出的 regression。

This is descriptive guidance for preserving a case, not a mandatory reasoning pipeline or a prerequisite for participation. No complete benchmark is required. Link to the source discussion, distinguish evidence from interpretation, and include only material that can be shared publicly.

这是案例沉淀建议，不是强制推理流水线，也不是参与门槛。不要求完整 benchmark。请链接原始讨论，区分证据与解释，并只收录可公开分享的材料。

Substantive scientific contributions may be credited in case records, release notes, contributor history, or relevant documentation. Credit reflects actual contribution; it does not promise paper authorship or automatic maintainer status.

实质性科研贡献可在案例记录、发布说明、贡献历史或相关文档中署名或致谢。认可应与实际贡献相匹配；不承诺论文作者资格或自动授予维护者身份。
